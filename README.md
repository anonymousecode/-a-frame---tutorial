# 🕶️ A-Frame Interactive Tutorial

This project is a beginner-friendly A-Frame scene showcasing custom components, click-based color toggling, marker placement, and built-in animations. It’s perfect for learning how to create interactive 3D experiences in the browser using [A-Frame](https://aframe.io/).

---

## 🚀 Features

- 🔄 Rotating box using A-Frame's `animation` component
- 🎨 Click to toggle color between original and red
- 📍 Click on the ground to spawn translucent red marker boxes
- 🧱 Custom A-Frame components using JavaScript

---

## 🧰 Getting Started

1. Clone or download this project.
2. Open `index.html` in a browser.

No server required — everything runs locally in your browser.
